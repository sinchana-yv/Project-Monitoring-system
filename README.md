# AVLOKAN

### AI-Powered Infrastructure Project Monitoring and Risk Prediction Platform

AVLOKAN is a web-based platform designed to monitor infrastructure projects and identify potential cost overruns and schedule delays using machine learning.

## Features

- Infrastructure project monitoring dashboard
- Project-wise risk analysis
- Cost overrun risk prediction
- Current schedule slippage risk prediction
- State-wise and sector-wise analysis
- High-risk project identification
- SHAP-based prediction explanations
- Interactive project search and filtering

## Technology Stack

### Frontend
