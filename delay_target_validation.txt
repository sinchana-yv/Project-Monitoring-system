TIME DELAY TARGET VALIDATION
========================================================================

Scope
-----
This report validates the 190 project-level labels currently retained by
the delay-target generation process. It does not train a model and does not
modify the Cost Overrun model, backend, frontend, or source datasets.

Classification policy
---------------------
CONFIRMED ACTUAL:
  Only an explicit field named "Actual Date of Completion",
  "Actual Completion Date", or "Actual Date of Completion (MM/YYYY)" was
  accepted as actual completion evidence.

REVISED/PLANNED:
  "Revised Completion Date (MM/YYYY)", "Revised DoC MM/YYYY", and
  "revised_doc" were treated as schedule estimates, not completed outcomes.

UNCERTAIN:
  "Actual/Revised Date of Completion (MM/YYYY)" and "actual_completion" are
  ambiguous because they combine actual and revised meanings. They were not
  counted as confirmed actual completion.

Dates were normalized to month precision. A project outcome was considered
valid only when both original/target and eventual dates were present and the
eventual date was not earlier than the original/target date. Duplicate
project outcomes were reduced to one project record, preferring valid
records, then explicit actual evidence, then the latest outcome/report
record. No completion date was inferred or fabricated.

FINAL DECISION
--------------
Do we have enough confirmed actual completion outcomes to train a credible
binary Time Delay model?

No.

There are only 21 confirmed explicit actual outcomes, all delayed, with
zero confirmed actual not-delayed outcomes. A binary classifier cannot learn
both classes from this outcome set. The 136 revised/planned-only outcomes
and 33 ambiguous actual/revised outcomes must not be relabeled as actual
completion merely to create a second class. Doing so would create label
noise and could turn schedule estimates into false completion outcomes.

The current data is insufficient for a credible binary Time Delay model.
More confirmed completed-project records, including both delayed and
on-time completions, are required before training.
